# 🧠 Glosario de AI — Para humanos reales

> Conocimiento real, entre pares, sin vender nada.  
> Hecho para las personas que aprenden **haciendo**, no estudiando.

---

## ¿De qué se trata esto?

Este repo nació de una conversación simple: hay demasiado ruido sobre AI y poca claridad.  
No es un curso. No hay certificados. No hay nada que comprar.

Es un glosario colaborativo, abierto, en español, donde cada concepto se explica como se lo explicarías a un amigo inteligente que no tiene idea del tema — con ejemplos reales y un ejercicio concreto para probarlo.

---

## 🗂️ Las 5 capas del conocimiento

| Capa | Tema | Conceptos |
|------|------|-----------|
| [1 — El modelo](./capa1-modelo/) | Qué es y cómo funciona | **LLM**, tokens, contexto, temperatura, alucinaciones |
| [2 — Hablarle](./capa2-prompts/) | Cómo darle instrucciones | **Prompt**, system prompt, rol, few-shot, instrucciones |
| [3 — Ampliar](./capa3-capacidades/) | Cómo extender sus capacidades | Tools/Skills, **MCP**, RAG, embeddings, memoria |
| [4 — Orquestar](./capa4-orquestacion/) | Cómo combinarlo todo | **Agente**, workflow, chain of thought, human-in-the-loop |
| [5 — Evaluar](./capa5-evaluacion/) | Cómo saber si funciona bien | Evaluación, benchmark, grounding, sesgo |
