# 🤝 Cómo contribuir

Gracias por querer aportar. Esto es lo único que necesitas saber:

## El espíritu del proyecto
- **Sin humo.** Si no entiendes algo al 100%, di qué parte te falta o pregunta.
- **Sin tecnicismos innecesarios.** Escribe como le explicarías esto a un amigo inteligente.
- **Sin vender nada.** No hay links de afiliados, ni cursos de pago.

## Cómo agregar un concepto nuevo
1. Copia la `PLANTILLA.md`.
2. Renombra el archivo en minúsculas (ej: `rag.md`).
3. Completa todos los campos; el campo **"Pruébalo"** es obligatorio.
4. Actualiza el `README.md` principal agregando el link al nuevo archivo en la sección de conceptos disponibles.
5. Abre un Pull Request con el título: `Add: [nombre del concepto]`.

## Lo que NO debe aparecer nunca
- Frases tipo "según la IA..." sin fuente concreta.
- Publicidad disfrazada de contenido.
- Conceptos a medias sin el ejercicio práctico.
